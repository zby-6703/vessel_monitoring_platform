# Offline Analysis Override

- Use the existing charcoal, cyan, and safety-orange VesselSight operations palette. Ignore generated purple/pink marketing colors.
- This is a work surface, not a landing page: compact upload panel, persistent task queue, and a large result inspection region.
- Never show sample detections or invented metrics. Empty, queued, running, failed, cancelled, and completed states must be explicit.
- Upload controls need visible labels, file-size feedback, parameter helper text, progress, cancellation, and recovery guidance.
- Completed results prioritize annotated media, vessel identity/draft table, evidence assets, then full-result download.
- Keep all controls at least 44 px high on narrow screens and collapse the two-column workspace into one column.
