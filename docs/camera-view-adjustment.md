# 云平台调整角度与平台监测的关系

同一摄像头的物理云台和镜头由所有控制端共享。云平台移动镜头后，本平台接收的实际视野也会变化，选择不同主流/辅助流不会隔离物理云台。

## 需要重新标定吗

就本平台现有标定方式而言，单纯左右旋转或上下调整，通常不需要重做 1×、2×、3×、4×、6×、8× 光学倍率标定。`CAMERA_ONVIF_ZOOM_CALIBRATION` 只保存“倍率 → 原生 Zoom 位置”的映射，水平/俯仰位置另外读取和保存。ONVIF 也分别定义 Pan/Tilt 与 Zoom 控制空间；它们可以分别移动。[ONVIF PTZ 规范](https://www.onvif.org/specs/srv/ptz/ONVIF-PTZ-Service-Spec.pdf)

需要区分以下三件事：

| 内容 | 调整角度后的处理 |
| --- | --- |
| 光学倍率与 Zoom 位置的映射 | 仅转动角度通常保留，检查已标定倍率反馈即可 |
| 本次监测的水平起始机位 | 干净停止后重新开始采集，平台自动记录当前角度作为新基准 |
| 监测区域、分界线、左右旋转上限和水线取景 | 按新画面检查，必要时修改并保存 |

如果更换设备/镜头，开启数字变焦或改变设备 Zoom 坐标范围，应复核倍率映射，必要时重新标定。ONVIF 的通用坐标空间可能随数字变焦等设备选项重映射，不能把旧归一化值无条件视为原倍率。[ONVIF PTZ 坐标空间定义](https://www.onvif.org/specs/2512/ONVIF-PTZ-Service-Spec-v2512.pdf)

## 推荐调整顺序

1. 在本平台点击“停止采集”，等待当前录像保存、镜头缩回 1×，并确认水平归位结束。不要在正在自动跟随时用另一控制端同时调整。
2. 再在摄像头云平台调好左右与上下角度。需要稳定机位时，关闭云平台的自动巡航/其他自动跟随。
3. 检查 1× 画面中的航道位置、目标筛选区域和两条原倍率分界线；检查放大后船名、吃水区域是否仍在实际画面内，再检查左右旋转允许范围。
4. 需要时修改参数并“保存并应用”，然后启动摄像头采集。平台初始化会确认 1×，再读取此时的云台位置，作为本次跟随的起始机位。

分界线仍分别是各自画面宽度的比例，调整角度不会修改已保存的百分比，但这些位置所对应的实际航道区域已经改变。尤其上下角度会改变水线在画面中的高度，平台目前仅自动左右跟随，不会自动上下追水线。

如果上一次跟随由于断电或通信异常尚未归位，平台保存着“旧机位待恢复”状态，下次开始时会先尝试恢复旧水平机位；此时直接在云平台调好新角度再启动，可能被拉回旧水平角度。应先完成旧会话恢复并干净停止，再按上述步骤调整。

自动跟随期间检测到其他控制端改变水平位置、明显改变俯仰或更换倍率时，平台会暂停当前跟随并尝试缩回/归位，避免使用错误的视野坐标。这项行为来自当前 `horizontal_follow.py` 与 `optical_following.py` 的位置复核逻辑，不等于多个控制端可以同时争用同一云台。
