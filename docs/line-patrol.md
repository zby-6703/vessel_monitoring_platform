# 原倍率与放大画面的分界线跟踪

现场默认配置启用 `line_patrol_enabled`，关闭 `zoom_view_limits_enabled`。在实时监测的“循环录制 → 自动跟随与分界线”中调整参数，再保存并应用；本机下次启动继续使用最新保存的配置，不因共享文件更新而自动覆盖。可点击“恢复默认配置”载入当前现场默认值，再保存应用。切换流程或改变分界线/左右上限时，会收尾当前录像并归位，从下一艘船使用新设置。各电脑更新应先关闭平台再拉取代码。

## 两个空间独立设置

所有 x 坐标从各自画面左侧 0 到右侧 1，原倍率为已标定的 1×、水平原机位；放大空间是镜头当前倍率和朝向下的实际画面。界面显示当前空间的两条分界线，线和标签仅用于预览，不写入保存的视频。镜头倍率未确认时不叠加分界线。

| 参数 | 默认 | 用途 |
| --- | --- | --- |
| `overview_line_left` | 1/3 | 原倍率左分界线；左→右船头放大触发线、右→左船尾停止重复线 |
| `overview_line_right` | 2/3 | 原倍率右分界线；右→左船头放大触发线、左→右船尾停止重复线 |
| `detail_line_left` | 1/3 | 放大画面左分界线；左→右船尾越过此第一条线后开始右旋 |
| `detail_line_right` | 2/3 | 放大画面右分界线；右→左船尾越过此第一条线后开始左旋 |
| `pan_max_left_travel_ratio` | 0.15 | 向左偏离原机位的最大范围 |
| `pan_max_right_travel_ratio` | 0.15 | 向右偏离原机位的最大范围 |
| `pan_step_limit` | 1.6 | 单步旋转的画面宽度。界面显示 80%，1.0 对应半幅画面 |
| `pan_max_steps` | 2 | 每艘船的最大旋转步数，所有放大轮次累计 |

每个空间要求 `0 < 左线 < 右线 < 1`。两个旋转上限分别为设备声明水平全行程的比例，可独立设为 0–40%，0 禁止对应方向自动旋转，设备物理边界仍生效；这些比例尚未标定为真实角度。原倍率空间不做自动旋转。相对旋转使用零俯仰位移，绝对定位和归位保留当前俯仰。

## 左→右的完整流程

1. 首次确认合格移动目标时打开一段录像，以原倍率记录；根据进入画面的边缘或连续横向位移确认方向，右侧框边视为船头、左侧视为船尾。方向无法确定时继续原倍率录像。
2. 船头达到或跨过原倍率左线，至少两次连续新观测确认，且持续满足“回 1× 后稳定等待”时长后，选择已标定倍率放大。检测框退回线前或漏检时重置确认，间隔的越线抖动不会累计；重复送达的同一来源帧不累计次数。不等待完整船尾入画，不在 1× 下预先追船，也不因船体中心将暂时处于放大画面外而压低倍率。
3. 等待同一艘船进入放大画面。首次进入前的空画面不算船尾离场；默认最多等待 45 秒。目标进入后保持本轮倍率，至少观察 12 秒。
4. 船尾达到放大画面沿行船方向的第一条线（左线）时，按当前画面宽度的 80% 向右移动一步，默认间隔 2 秒。超出相对移动范围的步长会根据已测得的视野与云台位置换算，执行一次水平绝对定位。剩余行程不足时缩短步长。尚无换算的设备先用最多 30% 的画面宽度测量，这一步也计入步数。到位后用新画面检查船尾，镜头提前转到船头前方时重新等待同一艘船入画。
5. 同一艘船默认最多旋转 2 步，先达到右旋范围上限时也会停转并保持当前角度录像。确认船尾离开放大画面后缩回 1× 并恢复原水平机位。归位不占用步数。默认离场需要 5 秒且至少三次新空观测，短时漏检、旧检测、镜头运动和对焦搜索不作为离场证据。
6. 在恢复的原倍率画面重新确认同一艘船：船尾仍在原倍率右线左侧时，再执行放大、等待、跟随、离场和归位；船尾达到或越过原倍率右线后，本艘船不再放大，保持原倍率录到船尾离开整幅画面并确认离场。
7. 整艘船的所有放大轮次、归位和原倍率尾段保存为同一个 MP4；仅最后的原倍率离场才正常关闭录像。随后重新选船。

右→左对称：左框边为船头、右框边为船尾；原倍率右线触发放大，船尾越过放大画面沿行进方向的第一条线（右线）后触发左旋，原倍率船尾达到左线后不再重复。

原倍率画面的放大入口线和停止重复线保持原有语义，只有放大画面的旋转触发提前到第一条线。你已保存的分界线百分比继续保留。预览显示已保存应用的参数，每张推理画面携带自身的倍率/分界线快照；发送对应画面后才把该帧检测交给镜头控制，避免未保存参数或状态轮询延迟导致显示与实际触发不一致。每次放大在录像作业信息的 `patrol_events` 中记录船头/船尾位置、入口线和连续确认次数，方便核对。

录像的 `patrol_events` 记录每轮跟随启动时的船尾位置、分界线和请求步长。`pan_events` 记录每步的发令时间、到位时间、位置反馈、累计步数以及是否达到步数上限。每次旋转前后用同一份设备回读核对云台位置与光学倍率。

## 手动光学倍率

在实时监测中选择“手动镜头”，可使用“光学变焦”：缩小一档、放大一档以及设备已标定倍率的快捷按钮（当前同镜头配置为 1×、2×、3×、4×、6×、8×）。它们调用 `POST /api/camera/zoom`，以绝对位置移动真实镜头，只有实际到位反馈匹配请求倍率才显示成功；未标定倍率不能使用。1× 只返回原倍率，不修改已保存机位或监测参数。

自动循环占用镜头时按钮禁用。可停止采集并等待归位，或关闭“循环录制”并等待归位后调倍；后一种方式可保留实时检测预览。手动调倍期间拦截自动初始化、其他手动镜头操作、启动采集和区域对焦；“停止运动”仍可取消当前动作。关闭平台或更新代码时也会等待手动镜头动作结束。

## 倍率与目标关联

关闭“按完整船体竖直视野限制倍率”后，倍率不受船舶竖直位置和竖直视野边界压低。例如参考船高 16.2%、目标高度 100% 时建议约 6.17×，存在 6× 标定且最大倍率允许时选择 6×；不插值生成未标定位置。仍保留设置中的倍率上限和真实到位反馈。可手动重新开启完整船体竖直视野限制；旧配置未启用分界线模式时仍兼容之前的主体等待与居中策略。

每轮倍率保持到离开放大画面，下一轮在原倍率画面重新估计船高。固定俯仰下允许裁切，因此能否看到船名/吃水区域仍要结合真实机位、水线、分辨率和光照检查。

目标跨视野时要求参考坐标、船高、外观或进入方向相容；新关联需要唯一候选、至少三次新观测且持续 0.3 秒。灰度画面存在多个相容船体时继续录像，不强行换绑或移动。放大后始终未能确认目标时，超时归位并保留原倍率录像，本艘船不再重复放大。手动停止、镜头异常、最长单段时长和存储保护仍能终止当前过程，原机位恢复不依赖下一帧到来。

## 验证

`backend/tests/test_line_patrol.py` 使用隔离录像目录与模拟的已确认物理镜头，覆盖双向两空间分界线、可调触发线、独立左右上限、初次空画面等待、范围到顶保持、同段重复放大、原倍率尾段、旧观测拒绝、多船歧义和重复放大中停止；其中完整多轮流程同时生成并解码真实 MP4，验证归位过程中没有提前关闭文件。`test_horizontal_follow.py` 验证真实 ONVIF 请求的横向范围、零范围禁转和垂直分量为零。它们验证控制与媒体保存逻辑，不替代自然过船和吃水刻度清晰度验收。
